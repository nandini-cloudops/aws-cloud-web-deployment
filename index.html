Explore Project

About the Project

This project demonstrates how a website can be hosted on an AWS EC2 instance and served to users through Nginx.

AWS EC2

A virtual server used to host the website in the cloud.

Linux

Used to manage the server, files, packages and services.

Nginx

A web server that delivers the website to visitors.

GitHub

Stores the project source code and documentation.

How It Works

User → Internet → AWS EC2 → Nginx → Website

The user opens the server's public address. Nginx receives the HTTP request and serves the website files.
